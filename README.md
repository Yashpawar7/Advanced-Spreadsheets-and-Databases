# Advanced Spreadsheet Application for Financial Decision-Making
## Designed and developed an Excel-based financial model, including a cash flow forecast, to enable "What-If" analyses for a manufacturing company. Integrated advanced Excel features such as VBA, Macros, pivot tables, data validation, conditional formatting, monte carlo simulation and a dynamic dashboard to facilitate intuitive decision-making for non-technical managers
Skills: Advanced Excel Modeling · VBA & Macros · Monte Carlo Simulation · Dashboard Design & Data Visualization · Data Validation & Quality Assurance
